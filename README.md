# Powerful CLI Apps in Go
Repository di studio ed esercizi seguendo il libro **"Powerful Command-Line Applications in Go: Build Fast and Maintainable Tools"** di Ricardo Gerardi (The Pragmatic Bookshelf).

## Obiettivo

Questo progetto raccoglie il codice, gli esercizi e le note che sviluppo seguendo il libro, con lo scopo di imparare a progettare e costruire applicazioni a riga di comando robuste, testabili e mantenibili in Go: parsing degli argomenti, gestione di stdin/stdout/stderr, gestione degli errori idiomatica, testing, concorrenza, e distribuzione di binari.

## Struttura del repository
Ogni cartella corrisponde (indicativamente) a un capitolo del libro e contiene il codice sorgente e i test.

## Note
Questo repository ha finalità puramente didattiche: il codice segue (e talvolta amplia con esperimenti personali) gli esempi proposti nel libro. Non è pensato come libreria o tool di produzione.

## Riferimenti
- Ricardo Gerardi, *Powerful Command-Line Applications in Go: Build Fast and Maintainable Tools*, The Pragmatic Bookshelf.
